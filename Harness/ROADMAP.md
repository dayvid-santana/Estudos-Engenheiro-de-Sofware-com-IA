# Roadmap de estudo

Este mapa ajuda a escolher por onde começar e a localizar cada conceito. Use os roadmaps temáticos para seguir uma trilha com mais detalhe. As notas vinculadas contêm as explicações; este arquivo organiza a navegação.

## Em 30 segundos

- Comece por **Fundamentos** se Harness ou agentes ainda forem conceitos novos.
- Siga **Construção e operação** para estruturar, proteger e avaliar um agente.
- Siga **LangChain, MCP e APIs** para aplicar os conceitos em uma aplicação.
- Consulte o roadmap temático quando quiser uma sequência completa de um assunto.

## Como avançar

1. Escolha uma pergunta da tabela de trilhas.
2. Leia a seção **Em 30 segundos** de cada nota antes de decidir se precisa do detalhe.
3. Experimente os exemplos apenas em ambiente adequado e consulte as fontes oficiais para detalhes sujeitos a mudanças.
4. Volte ao mapa de conceitos para encontrar o próximo assunto.

Os caminhos são sugestões de aprendizagem, não pré-requisitos rígidos. Se já conhece um assunto, pule para a nota indicada pelo mapa.
