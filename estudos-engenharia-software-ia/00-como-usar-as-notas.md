# Como usar as notas

Escolha uma nota → leia o ponto de partida → tente responder às perguntas sem consultar → pesquise uma delas → faça o exercício → explique o conceito com suas palavras → registre evidências e dúvidas → siga uma conexão relevante.

- Não é necessário completar todas as seções de uma vez.
- Registrar uma dúvida bem formulada também é progresso.
- Evite copiar explicações sem reformulá-las.
- Separe o que foi lido, o que foi observado e o que ainda é hipótese.
- Anote a fonte de descobertas importantes.
- Revisite notas antigas quando uma experiência mudar sua compreensão.
- Se uma nota crescer demais, crie uma nota complementar e conecte-a à original.

Use o Harness que estiver explorando como terreno de observação, sem presumir que a implementação corresponde a uma definição de livro. Diferencie comportamento observado de intenção aparente. As seções pessoais ficam para suas descobertas; nenhuma nota presume que um conceito já foi aprendido.
