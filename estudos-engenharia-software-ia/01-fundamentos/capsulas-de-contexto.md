# Cápsulas de contexto

## Ponto de partida

Cápsula de contexto é uma expressão usada para um pacote delimitado de informações úteis a uma tarefa ou agente. Não há uma definição universal: pode ser uma seleção de instruções, fatos, histórico e referências com escopo explícito.

**Quando investigar:** quando diferentes etapas precisam compartilhar apenas uma parte do conhecimento disponível.

## Investigue

- Que critério inclui ou remove informação de uma cápsula?
- Como registrar origem, validade e limites do conteúdo encapsulado?
- Em que se diferencia de uma janela de contexto ou de memória persistente no Harness estudado?

## Experimente

Monte uma cápsula manual para uma tarefa pequena, anotando cada item e sua origem.
