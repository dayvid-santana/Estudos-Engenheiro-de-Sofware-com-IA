# System Prompt

## Ponto de partida

System Prompt é uma mensagem de instrução associada à configuração de uma conversa com um modelo. Sua precedência e tratamento dependem da API e do sistema; texto de prompt sozinho não substitui controles de acesso no software.

**Quando investigar:** ao estudar como objetivos, limites e formato de resposta são comunicados ao modelo.

## Investigue

- Como o Harness combina instrução de sistema, entrada do usuário e contexto recuperado?
- Que instrução conflitante o modelo pode receber de conteúdo não confiável?
- Quais limites estão reforçados fora do prompt por validação ou autorização?

## Experimente

Leia um prompt de estudo e classifique cada trecho como objetivo, restrição, contexto ou formato esperado.
