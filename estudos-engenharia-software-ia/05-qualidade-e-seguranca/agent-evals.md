# Agent Evals

## Ponto de partida

Agent Evals avaliam o desempenho de um sistema com agente em tarefas representativas, considerando resultados, etapas ou restrições relevantes. Como o comportamento pode variar, exemplos isolados não caracterizam bem a qualidade; conjunto de casos, critérios e execução precisam ser registrados.

**Quando investigar:** ao verificar se uma mudança no Harness melhorou ou prejudicou tarefas reais.

## Investigue

- Qual evidência separaria uma resposta convincente de uma tarefa realmente concluída?
- Como os casos cobrem sucesso, falha, ambiguidade e uso indevido de ferramenta?
- Que mudança de métrica ocultaria uma regressão importante?

## Experimente

Defina três casos de avaliação para uma tarefa conhecida, incluindo um caso de erro, sem atribuir solução antecipada.
